09 — Mechanics, as drawn above

What this mockup assumes

Who is asked
Everyone rejected or voided. No draw, no odds, no chance element anywhere.
The question
Rewrite the rejected proposal so it passes all five gates, in 50 words. Criteria published in full.
Attempts
One. Recorded against the docket so it cannot be retried.
Winner
First correct answer in the cycle. Caps payouts at one per cycle by construction.
Judged by
The same five gates, the same model, the same clamp. No new discretion, no hidden criteria.
Published
The winning rewrite goes on the ledger beside the payout, so anyone can see it earned it.
Prize
5% of Treasury, locked to tokens at answer time like any award.
Cycle limit
Separate from the one approval per cycle — the rejection stands, so it is not an approval.

Still needs a lawyer. Skill-first avoids the complex-lottery rule, but s.14(5) only treats this as skill if the question genuinely stops a significant proportion from winning. That is a judgement about the real audience, not something a mockup settles.

Still needs the economics. 5% of Treasury is the constitutional maximum for a single award, and sweeping is unbuilt, so nothing currently refills the Treasury at all. Both need solving before this pays out once.

Still needs a hole in the guard. The publisher strips @mentions from every ruling before posting. Tagging a handle needs a deliberate, validated exception — ^[A-Za-z0-9_]{4,15}$ — not the guard removed.
